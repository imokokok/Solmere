# 100饭店

可接入大游戏的 Godot 4.7.2 / GDScript / 2D 自由烹饪小游戏。窗口采用白天暖色厨房，食材、器具、人物使用重新绘制的独立素材。当前为可玩的开发版本。

## 开始游玩

菜谱跟做：按底部「菜谱」或 J，打开一道菜后选“照着做这道菜”。底部会根据真实取物、切配、入锅、熟度和装盘推进。先试厨房示范“番茄清汤面”；自己的菜谱保留实拍与拼贴，并整理具体做法。范围和近似说明见 [厨房手记与跟做](docs/RECIPE_GUIDE_20260925.md)。

运行 Windows 试玩包中的 AfterHoursKitchen.exe；名字保留用于兼容旧启动路径，窗口标题为「100饭店」。源码用 Godot 4.7.2 Standard 导入 project.godot，按 F5。欢迎页可开始营业或练习。

## 翻炒、出菜与翻页

握住锅柄，在炉灶附近向上轻甩，锅中的固体食材会按各自位置离锅、翻面并落回；有较多汤水时请用厨具翻拌，避免把汤当作干炒。原有锅铲和木勺接触翻拌仍可使用。出餐后先看到由当前真实摆盘绘制的成品展示，再看顾客的评价。打开菜谱后可点“上一页 / 下一页”或按左右方向键翻动；书架缩略页与展开页使用同一份菜谱记录。界面沿用本工程的纸纹、字体和手绘食材。

## 鼠标操作

| 对象 | 实际操作 |
| --- | --- |
| 冰箱、台面食材、奇异材料架 | 按住材料拖到台面、菜板或锅中，松开放下；取得的是完整材料 |
| 打开全部食材 | 搜索和分类选择全部当前可用材料；常用材料分区陈列，避免挤满场景 |
| 主厨刀 | 按住右侧刀柄，让刀刃划过菜板上的食材，生成两个真实切块；松手停止跟随。拖任一切块可整批入锅，各块仍独立受热和碰撞 |
| 菜板 | 固定在右侧备菜区，不能拖动；板上的食材和切块仍可拿取、切配及整批入锅 |
| 抹布 | 关火并装盘后，按住抹布拖到水龙头下打湿，再来回擦过空锅底；松手归位。脏抹布可冲洗，没擦净的残味会进入下一道菜 |
| 三把厨具 | 木铲、木勺、黑锅铲都能拿起。铲头碰到食材才推动；木勺有三段物理勺沿，食物显示在勺底和前沿之间，轻移可承托，快速甩动或滚轮倾勺会滑出 |
| 锅 | 拖锅柄自由移动，松手落台；按住右键倾倒或用滚轮调角，让食物从锅口实际落下 |
| 水槽 | 按住水龙头把手向下转开、向上回转关闭；把锅移至水流下接水。持续放水会先灌满水槽，再逐渐淹没厨房；关闭后积水逐渐排走 |
| 小火 / 中火 / 大火 / 关火 | 控制真实受热速度；各材料独立记录熟度和焦糊 |
| 调料 | 拿起容器后在锅上方按住鼠标，按类型撒粉、倒液体或挤酱；松手停止，容器本身不进入配方 |
| 溢出的污渍 | 空手点击擦掉；持续挤酱会溢出，溢出部分不算入料理 |
| 盘子 | 拖动会带着已装盘食物一起移动；单击打开较小的摆盘页 |
| 摆盘页 | 同一次切出的整组食物或全部食物可一次装盘，再自由移动旋转、淋酱、拍照；也能保留火候回锅 |
| 聊聊口味 | 向当前客人了解偏好；实际影响备料选择 |
| 出餐 | 只有实际装进盘子的完整料理才能交付；评价食材、切配、火候和口味，显示餐费、小费或赔偿 |
| 丢弃 / 清理台面 | 手中有材料时丢弃该材料，空手时移走锅、盘中的食材及散落物和洒漏；锅内残味仍需实际清洗 |

没有放大菜板：切菜直接在右侧台面完成。底部操作提示有独立区域，不覆盖厨房。键盘快捷键是可选辅助；Q 放下、TAB 食材、J 菜谱、P 海报、ESC 暂停。

## 经营和食材

- 数据库含 105 种材料定义；按“无鱼”规则，鱼和三文鱼不进入取材与点单池，当前可用 103 种。物件具有质量、摩擦、受控碰撞和口味标签。
- 前景同时陈列 37 个取材入口；冰箱第一页可页内滚动，集中显示 18 种常用食物，已接入的团队原画均在其中。其余通过食材柜或陈列架选择。
- 一锅最多容纳 6 份来源食材、合计 48 个物理切块。只有实际落入锅里的材料才计入料理；同源切块独立记录几何、物理身份和受热，切割守恒质量，每个分支最多沿刀刃细切八次。
- 各食材分别受热，小中大火速度不同；生食、熟食、烧焦根据不同客人口味评价。BEETMAN 偏爱一点焦边，但其他客人可能不喜欢。
- 客人统一等待 120 秒。菜谱、海报、摆盘和暂停界面打开时，小游戏计时与受热暂停。正式班次默认 12 分钟现实游玩时间，画面时钟从 10:00 走到 14:00。
- 评分低于 20 分不收餐费并扣赔偿；20–80 分按分数收取餐费；高于 80 分另有金额不等的小费。结算明确列出三项金额。
- 顾客使用主游戏 12 位 NPC 的正式 ID 与名字；角色各有习惯、偏好、忌口、评价和离开台词。
- 声音来自 37 条已核对 CC0 的外部录音，剪辑为 52 个片段；区分煎蛋、蔬菜、肉类、浓酱、沸水、倒油、挤酱、撒粉及木/金属厨具接触。已移除程序拟音和生成脚本。商用无需强制署名，仍保留逐条来源、许可与加工记录；素材及近似边界见 [音频说明](docs/AUDIO.md)。

## DIY 菜谱和海报

新建作品是一张完全空白的纸。纸外列出当前料理实际用料；锅空时可使用上一道料理，也可以不做菜直接创作。

素材由玩家主动加入：文字、食材、料理照片、导入照片、贴纸和胶带。支持移动、旋转、缩放、复制、删除、图层调整、自由画笔与多边形裁剪。胶带还能改变颜色、独立长宽，并拖动端点拉长；撤销和保存会保留设置。

摆盘照片只拍餐盘，不含界面或选中框，PNG 为 640×357；拍照后由玩家决定是否放进菜谱。已有菜谱可继续编辑、保存修改或另存新作品。打开已保存的作品，选择“分享这一页”导出 HTML 或单道 JSON；HTML 自带纸页图、做法与可重新导入的附件，朋友无需游戏也能阅读。不会自动上传到服务器，整本导出仍保留在菜谱库中。
