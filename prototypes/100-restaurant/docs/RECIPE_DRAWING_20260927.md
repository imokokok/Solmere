# 2026-09-27 用涂鸦笔画图解菜谱

按用户的新参考改造主要 DIY 入口：竖版纸页已有材料和四条做法文字，顶部留给玩家亲手写菜名，各步骤旁留给玩家画配图。参考图只用于页面逻辑，没有复制图像、文字、字体或角色。

## 已实现并验证

- 「新建 DIY 菜谱」打开竖版图解工作台，默认拿涂鸦笔。顶端没有输入菜名的文本框；页面展示的菜名和步骤插图均来自玩家的真实笔画数据，不用字体、照片、贴纸或成品素材代替。
- 尚未做菜时预排一份明确标记为“做法示例”的番茄面文字；已有本餐料理时按其成品状态整理材料和四组步骤，不冒充历史操作时间线。文字与真实烹饪记录分开，示例页的 `dish.ingredients` 始终为空。
- 细笔、铅笔、宽笔及五种颜色；圆润的细笔连接；局部橡皮擦会分割碰到的笔画，保留未擦部分和预写文字。单次落笔或擦除为一次撤销操作；保留重做。笔画容量由 128 提升到 512，统一画布、菜谱仓库和海报仓库校验，避免完整手写标题与插图被截断。
- 「改材料和步骤」在同一张纸上直接编辑原生 TextEdit，显示和编辑使用同源手写字体与排版。文字修改、橡皮擦、绘画都参与撤销/重做。
- 保存需要顶部有手写笔迹，且至少一个步骤配图区有玩家笔画，预写说明本身不能冒充玩家完成作品。没有文字识别；菜谱册用“手绘菜谱 N”作索引，纸面菜名保持原始笔迹。
- 未保存草稿按图解/拼贴/已有作品身份隔离；永久保存同时保留预写说明与每条可编辑笔画，重开可继续画、修改或另存。仅编辑预写文字也会保留本次进程草稿。
- 书架、展开阅读和离线分享使用同一份完整竖版纸面，避免阅读时把手写菜名替换成索引名，或把插图压到旧横版拼贴框里。旧作品仍按原格式渲染；「自由拼贴手记」保留旧工作台及照片/贴纸能力。

## 边界

已实现但未人工验收：持续人工自由绘画、Windows 触控笔与不同输入法。自动输入与 GPU 验证不冒充这些结论。草稿仅在当次进程保留，退出前需永久保存。预排的示例文字和按成品状态归纳的文字不是实际烹饪历史；纸上绘画不改变锅中食物或已完成配方。远程 CI 以本次推送提交的实际运行结果为准。
