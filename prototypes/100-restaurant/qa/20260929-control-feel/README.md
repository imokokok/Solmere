# 操作手感修正 · 2026-09-29

本轮针对“操作和反馈别扭”收敛抓取控制。保持现有手绘素材、烹饪状态及材质差别；没有新增震屏、粒子、音量或灾难效果。

## 修复与原因

| 实际问题 | 修改后的行为 | 实现边界 |
| --- | --- | --- |
| 普通匀速拖动也有明显滞后，手停下后物体还在追赶 | 抓取力同时参考指针位置与经过滤波的指针速度，减少持续位置误差 | 原生刚体仍负责位置和接触；力上限、质量差别、自由落体和碰撞材料不变 |
| 快速松手后，工具或整份切片在补完移动期间无法重新抓住 | 点击正在移动的可见物体立即恢复拖拽，取消旧放下目的地 | 保留当前抓点、姿态与独立切块；不复制食材或丢失同批质量 |
| 实机发现收回锅边的铲子会将整口锅横拉出灶台 | 收回工具筒时先抬出锅沿，再移回筒口；铲勺的最大拖拽力按自重限制 | 针对接近直立的锅和真实筒口；保持碰撞，不冻结锅，不瞬移道具 |

参数保存在 `modules/restaurant/data/physical_interaction.json`。目标速度上限为 900 场景像素/秒，速度滤波率为 32/秒，速度前馈系数为 0.7。铲勺抓取力上限为自身质量乘 6000，黑铲/木铲为 960、勺子为 480；这是场景单位下的游戏调校，不是实测人体力学常数。

## 可重复测量

相同的 400 场景像素/秒直线手势，120 Hz 原生物理模拟，统计后半秒的平均抓点距离：

| 刚体质量 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 0.1 kg | 29.92 px | 6.70 px |
| 0.5 kg | 38.72 px | 9.38 px |
| 1.2 kg | 44.56 px | 11.16 px |

60 Hz / 120 Hz、三种重量的停止检查均要求 0.35 秒内稳定，越过目标的距离小于 12 像素；实测稳定时间为 0.183–0.233 秒，越过目标约 5.60–6.27 像素。此测量是无接触的控制器基准，不是整机鼠标延迟或所有碰撞姿态的承诺。

旧的锅边收铲复现使锅横移约 142 场景像素；新增真实输入回归对三件工具都要求归筒成功，锅偏移小于 8 像素。保留修改前日志，不把只有最终成功的记录当作复现证据。

## 检查范围

- 58 项快速手势检查：三件铲勺的快速取出、移动中重新抓取、腕部姿态、归筒、锅边收回；锅盖、敲蛋、暂停；切块整体抓取、重新抓取、质量与清理；盐瓶库存及余量。
- 43 项抓取/水量/锅盖检查：6 组实际刚体跟随、停止越界、有限力，以及锅承托、1700 ml 液体转移和压力顶盖。
- 本轮主游戏衔接检查仍要求 25 项通过。
- 全量运行暴露海绵测试的时序竞争：固定 0.3 秒渲染计时没有保证水已落地，从物理帧恢复后发出的合成鼠标事件也可能尚在输入队列。测试现在有上限地等待实际台面积水，且明确刷新输入队列后再观察状态，保留抓取与吸水量断言。生产水流和海绵没有因此改写；原始失败记录保留。
- 全量结果见 `checks/summary.json`；源文件、EXE 与验证范围见 `RELEASE.json`。最终远程提交、main 和对应 CI 证明随 Windows 包 `DELIVERY.json` 保存。
