# Solmere · 纯拼贴书信事务所

双击 `Start-Game.cmd` 开始。`Start-Demo.cmd` 使用独立演示存档。需要 Godot 4.5.1 或更高版本；便携包附带运行时，不需要安装 Python 或启动服务器。

## 怎么玩

1. 点右上纸叠「小镇来信」，读居民的委托，点「拿这些纸，开始拼贴」。没有前置解谜、查名字、归组或选择题。
2. 左侧纸签翻到报纸、书店、票据、来信、照片或纪念。点开原件，再拿起剪刀，点词条剪下。原件留下缺口，剪下的材料先放到左下收纳盘。书下箭头翻页；连接词和标点在「书店」分类。
3. 拖动纸片到 A4 信纸。滚轮旋转；抓纸片右下角拖动可以独立拉宽、拉高。只有拿起时显示细框。
4. 拿起一个词条，再点右侧文具盒中的剪刀，可以剪成单字重排。「放回原件」会将纸片还给原件；同一词条的字全部还回后，原词才恢复。
5. 「纸片抽屉」提供日报、书店留言、演出单、咖啡馆小卡、海岸天气、街坊留言、心意小条。全部使用现代日常语言，没有古风文案、打字机、输入框或手写工具。
6. 点右下「完成」给居民看看，确认没有误解他的心意；再次点「完成」，折纸两次，放入信封，贴邮票，盖邮戳。自由信、海上回信不需要居民确认。

桌面「拼贴示例」可查看一张由实际可用的字词、照片和纪念纸组成的参考排版，不会覆盖你的作品。文具盒里的纸叠切换牛皮纸、棉纸和深色纸；胶带卷拿一段胶带，压纸夹将选中的材料压到下面。悬停工具可看名称。照片和纪念分类点击整页后拿一份到收纳盘，仍可独立旋转、拉宽、拉高。所有底纸保持 A4 比例。

## 来信与保存

三份居民委托可直接开始。寄出后点击「次日来信」，居民的回信会给你留下一片永久纸片。海上来信当前为十二封本地虚构示例；寄出保存到本地，不表示已经发给真实玩家。共享纸片每封只能取一种，重复打开不会重复赠送。

同一拼贴组件用于居民委托、自由寄信和海上回信。草稿、位置、旋转、非等比缩放、图层、纸色、原件缺口与回信记录自动保存。旧的 V3 解谜存档会直接回到来信桌面，已做的拼贴保留。更早版本的作品与联网系统保留在 `Legacy.tscn`，不会被本版本清空。
