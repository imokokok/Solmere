# 书桌操作指南

普通入口 `Start-Game.cmd`；完整摆件示例 `Start-Demo.cmd`。示例独立保存，不覆盖普通草稿。先关闭自己正在编辑同一草稿的旧窗口，再重新启动。

## 以拼贴写信

1. 点击左侧素材夹。材料按类别收纳；字母、照片等四张一页，票据和广告两张一页，文字和乐谱一张一页。箭头翻页，伴随纸声。
2. 整张拖出来，或点开预览后用文具里的方框／自由刻刀裁剪。预览底部箭头可看下一张。中央 A4 信纸固定在桌面，不可拖到打字机。
3. 按住纸片时出现细小变换框。四角等比缩放、边缘拉伸、上方圆点旋转、小叉移除；松开鼠标后边框隐去。滚轮与 Q/E 快捷键仍可用。最新放上的纸片在最上。
4. 胶带有八种纹样，按住拉出后松开截断。胶棒可用但不强制翻背或固定；贴好后仍能调整。纯拼贴可以完成寄出。
5. 水粉先蘸颜料，选择浓淡与宽度。“只涂素材”受透明轮廓和裁边约束，“整页涂色”可经过多个纸片。涂鸦与水粉都可撤回上一笔。
6. 如需文字，使用“写几句话”，输入称呼、短句或落款。右侧打字机有独立纸，可以点击字母键、换行与删除；“替换纸张”保留拼贴，重新打开可撤回；“剪下纸片”把选区作为独立材料。
7. 正文支持编辑、粘贴、撤销、中文提交及 Unicode。显示会按节奏追上输入；满页暂停演出，由你按下一页继续，不自动卷动纸面。页角设置提供速度、书写音量、减少动态效果及重播。删掉文字也不会丢失后页拼贴。

每次看一张 A4，原作数据保留全部文字、各页纸片、位置、缩放、旋转和颜料。纸张下方没有常驻变换按钮，桌上没有大型装饰笔。

## 对话与信封

最右上角的小记录本可查看已经发生的对话、暂停后继续；来访者在对话框里提出需求与附件，不显示强制人物立绘。完成一份后还有后续委托。

点击右下纸签“寄出 →”后先等待剩余文字落完和笔尖抬起。依提示折叠信纸，从信封开口放入一部分，信纸会顺势落进袋内，再向下拖翻盖。拖火柴划过火柴盒，点燃蜡烛；将蜡粒放进勺里，悬在火焰上融化，倾倒后压章。倾倒失误会保留形状。打开信箱，把连同火漆的信放进去，关上盖子完成。

## 海上来信

左上满瓶带来来信，空瓶用于写新漂流信。满瓶流程：拿起瓶子 → 拔塞 → 拖瓶身向左或右倾斜，让瓶口朝下 → 纸卷滑出、落桌并自动展开 → 阅读。拔出的瓶塞可随手拖动或甩到桌上，有惯性、轻微弹跳和真实拔塞声。示例来信和准备好的回信都由文字、照片与纸片组成；可直接打开回信继续修改并“卷起寄出”。回信时原文留在手边。

寄出流程：从下沿卷纸 → 拔塞 → 对准瓶口逐渐插入 → 塞回按紧 → 将整瓶放到右侧海面。浪花与实录海声伴随放流。本地示例明确显示本地结果，随后换下一封；不会伪装成陌生玩家。

正式联网信需要邮局服务。发一封自己的新信后，需回复另一封才能继续自由发；回复不累积抵扣，不能自回或重复回复绕过。请求失败保留封好的作品及编号，可重试；服务端确认后才标记发送。正文保留原始 String，服务端接受最多 12000 字符并在超限时拒绝，客户端保留作品；PNG 是拼贴预览缓存。

## 保存与声音

重要操作、定时及正常关闭自动保存；示例与普通信隔离。默认历史目录仍是 `%APPDATA%\Godot\app_userdata\拼贴书信 · 海盐书信事务所\`，这是为兼容旧存档保留的内部目录名，显示名称为 Solmere。便携包不附玩家数据。

桌面不再放声音、语言和设置按钮。F1 打开书写偏好，F2 切换语言，F3 静音；书写音量可独立调整。裁剪、胶带、涂鸦、翻页、打字机、擦写和海浪使用相应录音；次要动作仍复用同类纸声或轻敲声。英文模式不翻译你已经写好的内容。
