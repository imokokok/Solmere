# 当前需求与覆盖关系 · 2026-09-27

本表以用户最后有效指示为准；实际证据见 VALIDATION.md。

| 要求 | 当前处理 |
| --- | --- |
| 拼贴为主，打字为辅 | 默认空白、移动工具、纯拼贴可寄；独立示例存档呈现完整拼贴作品。 |
| 单张 A4、无绿框 | 一次只看一张 A4；最新书写规格要求满页后手动翻页，因此保留同封信多页数据。 |
| 直接操作纸片 | 按住／拖动时才出现轻量四角／边缘／旋转柄；去掉侧栏加减及常驻底部条。 |
| 去掉翻背涂胶 | 胶棒保留可选实际涂抹，取消背面仪式、胶水完成门槛和固定后禁止重排。 |
| 大材料预览 | 文字与乐谱每页一件，票据与广告每页两件；其余每页四件，含前后翻页。 |
| 桌面整合与画风 | 平涂木桌、街海窗口、可拉百叶窗；同一实体素材本展开，纸页动画与录音；文具和独立打字机在右侧。 |
| 少量补充文字 | 原生编辑与 Unicode 队列分离，正常比例的动态悬笔、落墨和六段笔声，完整 String 保存。 |
| 文字节奏与满页 | Variable rhythm、backlog 加速、删除渐退、Normal/Fast/Instant、手动翻页、重播／跳过、减少动态效果。 |
| Finish 与现有封装连接 | 先排空队列并抬笔，再复用折信、入封、封蜡、实体信箱和漂流瓶。 |
| 丰富素材 | 678 条目＋24 A4 底纸；真实乐谱、扫描纸纹、小镇票据／文字、52 字母；不把条目数冒充下载原图数。 |
| 两类漂流瓶 | 满瓶拔塞、倾瓶倒出并自然展开，瓶塞可抛放，空瓶写新信，发一回一；本地虚构小岸、程远、何阿姨示例与真实联网状态明确分开。 |
| 海上完整体验 | 纸卷、塞子、逐步入瓶、塞紧、海浪与浪花；失败可重试且不丢作品。 |
| 来访者与记录 | 对话框、追问、附件、历史恢复；去掉桌面重复来信委托入口。 |
| 语言与素材权益 | 中文印刷素材约80.0%，文字采用附来源的经典原文；英文版原创文案英文。保留来源与许可，不提取商业参考游戏资产。 |
| 完整交付 | 操作演示视频、独立示例入口、源码与主游戏扩展、运行检查、便携包与 main 远端证明。 |

最新粘贴的书写规格覆盖旧“删除笔”的表现要求：只在辅助文字书写时出现正常比例的动态悬笔，去掉旧的大型摆设笔。用户随后再次明确拼贴为主，因此文字演出不会成为完成信件的硬门槛。未完整试玩 Kind Words / Paper Sky，也没有两作可复用资产的官方商用授权；采用已核实许可的替代素材。
