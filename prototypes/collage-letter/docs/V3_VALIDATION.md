# 纯拼贴版验证记录 · 2026-09-27

## 当前玩法

用户最新要求优先于最初 V3 包：去掉前面的解谜；不要打字机、键盘输入、手写或古风文字；所有表达靠剪字拼贴完成。

来信托盘 → 阅读一份居民委托 → 立即进入空白 A4 拼贴 → 剪取词条/拆成单字 → 移动、旋转、缩放、叠放 → 居民反馈 → 折信、入封、贴邮票、盖邮戳 → 次日回信与永久纸片。自由寄信和海上回信使用同一套拼贴组件。

## 验证

- Godot 4.5.1 GPU `tests/v3_flow_test.gd`：89 项检查通过。包含直接进入三份委托、没有打字 API/输入框、90 多个现代词条、示例中每个词均来自实际素材、剪切/原件缺口、拆字/完整词义与单字不冒充整句、归还原件、缩放旋转与存档、有效与越界表达、整套寄信、次日回信、赠片防重复、草稿恢复。
- Godot 4.7.2 GPU 宿主集成：进入手工店、营业时间、角色隔离存档、三种尺寸下 1440×810 子视口、录制声音、十二封离线来信、寄出后主游戏结算条件通过。`test_collage_viewport.gd` 转向当前测试；旧版检查文本保存在文档中。
- 实际 Windows 窗口已打开并观察到纯拼贴 UI 和可拖动词片；旧解谜窗口通过正常关闭保存后更新。用户正在使用的 `v3_live` 草稿没有清空或用示例覆盖。
- 修复旧回复草稿键 `REPLY_0.0` 与 `REPLY_0` 不匹配；修复复用旧存档时本次还没寄信就可能触发宿主结算；大量剪字的生成位置始终留在桌面可见范围。
- 剪字范例仅供查看，与创作草稿分离。保存包含位置、角度、非等比缩放、图层、底纸、剪切缺口和赠片记录。
- 演示由 `v3_demo_tour.gd` 在真实引擎中回放输入，记录游戏声音，完成委托寄出、次日回信、自由寄信、海上回信，并回到下一张空白纸；不是宣称人工逐帧试玩或线上真实玩家互寄。

## 当前范围

- 收发为本地虚构演示数据，三位居民与十二封海上来信。用户的旧版联网系统和作品仍保留在 Legacy 场景及原目录。本次不把离线发送冒充网上发布。
- 剪切以可见词条为单位，可再剪成每个字；可拖动和拼贴，不支持任意像素抠图。
- 居民仅核对事先标记的表达与边界，不是自然语言 AI 评分；自由信件没有这一步。
- 本地次日按钮模拟来信到达；宿主时钟负责环境光变化。
- Noto Sans SC 使用现代印刷字形与不同字重。新增素材文案为原创小镇日常文字，不复制参考图片中的诗文。
