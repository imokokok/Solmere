# Solmere · 拼贴书信

在一张 A4 信纸上，用照片、旧纸、票据、胶带和颜料表达心意。**拼贴是主体，打字是补充**：正常新信保持空白，默认拿放纸片，不要求填写正文，也不要求先刷背胶。屏幕一次只展示一张纸；补充文字超过一页时，手动翻到下一页继续。

## 启动与示例

- `Start-Game.cmd`：空白创作或恢复自己的草稿。
- `Start-Demo.cmd`：独立示例存档，首次打开预先摆好的“给小满的一阵海风”。不覆盖普通草稿。2026-09-27 使用新的示例存档名，旧示例另行保留；示例只填充一次，下一任务及其重启都保持空白。
- 左上有信纸的瓶子：拿起、拔塞、倾瓶倒出、自然展开后阅读。三封虚构来信分别来自十五岁小岸、三十八岁程远和七十二岁何阿姨，可查看准备好的拼贴回信，再亲手装瓶寄出。本地示例不发给真实玩家。
- 左上空瓶：写自己的漂流信。正式联机模式发一封新信后，需回一封别人的信；本地示例也有独立轮换和引导。
- `Start-Two-Players.cmd`：两个独立身份连接本机邮局。`Start-LAN-Server.cmd` 启动服务；尚未部署公共邮局。

便携包自带 Godot 和 Python。Git 源码需要 Godot 4.5.1+ 与 Python 3.10+；设置 `GODOT_BIN` 或把 Godot 加入 PATH，运行 `python server/launch.py`。玩家身份、私人草稿、数据库和引擎缓存均不进入源码或 ZIP。

## 桌上的东西

素材夹从同一本封面展开。文字与乐谱每页一件，票据与广告两件，其余四件。按住纸片或操作手柄时才出现细小变换框：四角等比缩放、边缘拉宽拉长、上方圆点旋转；平常隐藏。后放在上，纸边、接触阴影和拿起落下反馈表现厚度。

右侧打字机有独立纸张和可点击字母键；可替换正文并撤回，也可剪出打好的纸片。文具提供刻刀、胶带、涂鸦、水粉与可选胶棒，预览不再重复摆放同一排工具。去掉翻背刷胶和固定后无法移动的限制。百叶窗可拉开，窗外是街道与海。

“写几句话”使用原生输入处理编辑、选区、粘贴和中文提交；独立渲染队列表现文字、轻微落墨、正常比例的悬笔跟随和录音反馈。完整文字始终保留为 String，不依赖一张最终图片恢复。可选 Normal / Fast / Instant、音量和减少动态效果。收信也可重播书写或跳过。

委托保留对话、追问、历史和附件。实体投递仍是折信、连续入封、拖翻盖、点烛、融蜡压章、装入信箱；漂流投递是卷纸、拔塞、从瓶口插入、塞紧和入海，带浪花及实录海浪声。

## 材料与许可

**678 个可用条目**：100 图案、96 纸张、160 广告、120 文字、121 票据、17 乐谱剪片、6 画作、6 场景照片卡、52 独立大小写字母；另有 24 款 A4 底纸。条目不等于独立下载原图，数量没有冒充素材来源数。中文印刷素材占约 80.0%；文字类采用公共领域经典原文，英文页使用原版英文，玩家原文和既有裁片不被翻译。

96 张中文经典摘抄与 24 张英文摘抄均有作者、书名、来源及许可，标为 Maya 书店摘抄。乐谱明确标出 Scott Joplin《Original Rags》及页码。主游戏把观景台图集与玩家已冲洗照片接入照片类，客户附件单独归类。保留真实公共领域乐谱、扫描纹理及逐项来源清单。桌景为原创生成平涂插画；文具盒、素材本、打字机和光照由原生 2D 绘制，旧文具袋栅格作为历史资产保留但不再显示，见 [制作记录](assets/illustrated_office/PROVENANCE.md)。既有 Solmere 场景与用户字母不标为 CC0。Xiaolai 字体附 OFL；新增六段写字录音、擦写与海浪均记录源文件及 CC0 来源，不合成假录音。
