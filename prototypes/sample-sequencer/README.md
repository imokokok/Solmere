# Soulmere 声音小游戏

> let's make some noise，做一张属于你自己的唱片吧！

一个 Godot 4 声音小游戏原型。玩家选择从地图中收集到的声音，点亮格子、聆听，再把喜欢的组合保存成唱片。

## 运行

1. 使用 Godot 4.3 或更新版本打开本目录中的 `project.godot`。
2. 按 `F6` 或 `F5` 运行。

当前版本直接读取 `assets/audio/` 中的正式 WAV，不再使用程序合成占位音。

## 玩家操作

1. 选声音：在两种主声音和两种背景声音中选择。
2. 点格子：社区中心木门、杂货店玻璃瓶、木制棋子和书店翻页只需点亮或关闭；下面五行声音从低到高排列，可选择短、稍长、长、很长。
3. 聆听：声音会自动重复，可以一边听一边调整。
4. 保存：给结果取名，保存成一张可以重新打开的唱片。

## 当前声音与混音

- 固定声音：社区中心木门、杂货店玻璃瓶、木制棋子、书店翻页。
- 主声音二选一：社区中心玩具琴、B 家旧掌机；每套均提供 Do、Re、Mi、Sol、La。
- 背景声音二选一：眺望台风声、磁带底噪声；只需选择开或关。
- 杂货店玻璃瓶的音量是上一版的 60%。
- 眺望台风声和磁带底噪声的音量均是最初基准音量的 15%。
- 一圈有 16 格，会自动重复。

## 唱片存档

唱片数据保存在 `user://sample_records.json`，会同时保存：

- 点亮的格子和声音长短；
- 选择的主声音；
- 选择的背景声音及开关状态。

打开旧版唱片时，程序会保留原来的格子排列；旧玻璃瓶主声音会自动改为社区中心玩具琴。
