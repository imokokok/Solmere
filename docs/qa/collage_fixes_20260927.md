# 拼贴书信全流程问题修复

2026-09-27，北京时间；Godot 4.7.2 / macOS / OpenGL Compatibility。独立模块与主游戏集成副本同步修复。

## 修复结果

1. 成品纸面、正文范围和字号与编辑器保持一致。18 行中文在编辑器和成品中均分为两页；每页文本范围、照片位置、旋转和缩放不变，只有拼贴的额外页也保留。
2. 封信时保存所有成品页的 PNG，并随草稿持久化。寄信发送有序 `art_pages`，邮局事务保存全部页面，收件端可前后翻页。重启和网络重试沿用原成品字节及流水号。协议版本 3 提供能力检查和保存页数确认；旧邮局或确认页数不完整时保留草稿，不标记寄出成功。旧单页信与旧数据库自动迁移兼容。
3. 中文阅读按钮显示“重看书写”“跳过”；英文标签完整显示。按钮宽度按实际内容分配，多页原作与翻页控件同时在纸面阅读区域中可见。
