# 塔罗小摊重构与回归检查 · 2026-09-27

## 范围与保留项

新主场景位于 `extensions/myriorama_tarot/main.tscn`。`CasePresenter` 继承原 `table.gd`，只替换呈现与动效接线；原案件、抽牌规则、牌面、提问数据库、判断引擎、真相引擎和角色存档结构不改写。旧表格场景保留在 `scenes/case_table.tscn`，用于兼容回归。

当前玩家入口“听一个故事”进入原有两案：门外的目击者、五十人与四扇门；三轮各五张，全保留，选择六至八张主线，然后排列与陈述完整真相。不会用四卡自由创作替换案件。三卡自我观察入口独立保存，不冒充案件事实判断。四卡创作辅助模块仍在内部回归中，但不是当前玩家的故事入口。

78 张是视觉牌堆规模，实际可抽的仍是原来的有效牌集合。正逆位结构预留，当前统一正位。牌面、引导面、初始共用背面三者保持分离。

## 本轮修复

- 水平桌沿、正面坐视；背景与窗帘更简化，原始人物 PNG 哈希完全一致。
- 分层生图资产：窗景、窗帘、桌布、蜡烛、气泡；不把功能按钮画进背景。
- 删除玩家界面的音效开关、无意义装饰牌堆及额外 HUD。保留真实播放与全局音频总线。
- 右向左连续摊牌改为 1.70 秒；音频播放时长跟随动画。抽牌高亮和真实卡片移动保留。
- 气泡长段落分页，修复按钮底部裁切和悬停文字低对比。
- 修复轮次文字压住人物、单牌挡住蜡烛、返回单牌后气泡压住案件说明。
- 修复 15 张牌的解读按钮受主题最小高度影响而叠压下一排；小窗口复查通过。
- 引导背面可放大阅读；提问、改写建议、确认答案、笔记、选牌、交换、完整真相都是真控件。
- 真相/弹层隐藏旧卡面与连接光效，完成页不再盖住中央人物。
- 两套模式保存独立，退出宿主事务回滚后仍保留案件与自我观察记录。
- 导出模板不支持命令行场景替换，因此加入双重显式参数 `--tarot-preview --isolated-save` 的试玩入口；常规主菜单行为不变。

## 能力边界

本地规则问答仍是有限语义库，不是任意自然语言大模型。无法可靠理解时必须澄清，不把未知当 NO。人物保留原图，仅做轻微位置/呼吸状态反馈，没有声称新增表情绘制或口型。多轮测试降低回归风险，但不承诺任何输入/设备上绝无 bug。

资产和生图提示集见 `extensions/myriorama_tarot/assets/reader-scene/PROVENANCE.md`。没有改写其他协作者的关卡和小游戏。
