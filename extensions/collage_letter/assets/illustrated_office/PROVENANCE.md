# Illustrated office production assets

Restyled on 2026-09-27 using the built-in image generation tool. The two raster assets below use simplified matte 2D color planes, deliberately reduced surface detail and shallow illustrated shadows. The supplied kitchen image is a style reference only and is not redistributed in this module. These assets are original generated illustrations, not extracted from Kind Words or Paper Sky and not represented as CC0.

- `desk-room-v2.png`: flat wooden desk and coastal window (opaque).
- `tool-roll-v2.png`: illustrated stationery roll (original generated RGBA preserved).
- Closed and open folio: `scripts/desk_object.gd` renders a shaped cover, visible page block, tabs and ribbon from editable 2D primitives. The previous realistic `folio-v2.png` and `open-book-v2.png` were removed. Generated replacement drafts had alpha holes and were rejected; none of them ships.

The window blind, book opening and page turn, tools and material depth remain independent interactive Godot objects. Texture grain in collage paper and historical source materials is retained intentionally; the room and tools no longer use simulated photographic fabric/leather detail.
